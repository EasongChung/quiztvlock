# 使用说明

## 一、安装

### 方式 A：ADB 安装（推荐）

```bash
adb connect <电视IP>:5555
adb install quiztvlock-app-release.apk
```

### 方式 B：U 盘安装

把 APK 拷到 U 盘，插电视 USB 口，用电视自带的「高清播放器 / 文件管理」打开安装。
安装前需在电视「设置 → 账号与安全」里开启「允许安装未知来源应用」。

## 二、电视端设置

1. 打开桌面上的「答题电视锁」图标；
2. 各按钮按遥控器 OK 键循环切换数值：
   - 观看时长（分钟）：15 / 30 / 45 / 60 / 90 / 120
   - 答对每题奖励（分钟）：3 / 5 / 10 / 15
   - 每轮答题数量：3 / 5 / 10 / 20
   - 答错追加题数：1 / 2 / 3
3. 应用启动后即开始守护，**无需手动点开始**（点「开始守护计时」可随时生效）。

## 三、家长 WebUI（手机管理）

1. 手机与电视连同一 Wi-Fi；
2. 浏览器打开屏幕上显示的地址：`http://电视IP:36789`；
3. 登录：默认账号 `admin`，密码 `123456`；
4. 功能：
   - **状态**：观看中 / 答题中、剩余分钟、待答题数；
   - **操作**：立即开始答题、家长 PIN 解锁、重置观看时长；
   - **规则设置**：观看时长、每轮题数、答对奖励、答错追加、**题库开关（语文/数学/英语）**；
   - **题库**：四选一添加自定义题、删除题目；
   - **账号安全**：修改 WebUI 账号密码。

> WebUI 端口固定为 **36789**。账号密码存在电视本地，修改后请牢记。

## 四、孩子使用流程

1. 电视开机 → 应用自启；若上轮答题未答完，**直接进入答题页**；
2. 答题页用遥控器上下键选答案、OK 提交；
3. 答对 → 奖励分钟数 + 提示后继续；答错 → 追加题目；
4. 本轮全部答完 → 视频自动恢复播放，观看倒计时继续；
5. 观看时长用完 → 再次进入答题页。

## 五、家长 PIN 解锁（电视上）

答题页右下角「家长解锁」→ 输入 PIN（默认 `1234`）→ 直接结束本轮。
WebUI 的「家长 PIN 解锁」功能同样。

## 六、注意事项

- 部分小米电视需在「安全中心」把本应用加入后台白名单，防止被清理；
- 「自动暂停播放」通过媒体键 `KEYCODE_MEDIA_PAUSE` 实现，
  对系统播放器、大部分国产视频 App 有效；个别 App 若不响应媒体键，
  最多表现为声音继续播放（画面已被答题页覆盖）；
- 卸载应用即彻底解除所有限制（无需 root）。
