# 使用说明

## 一、安装

### 方式 A：ADB 安装（推荐）

```bash
adb connect <电视IP>:5555
adb install quiztvlock-app-release.apk
```

### 方式 B：U 盘安装

把 APK 拷到 U 盘，插电视 USB 口，用电视自带的「高清播放器 / 文件管理」打开安装。
安装前需在电视「设置 → 账号与安全」里开启「允许安装未知来源应用」。

## 二、电视端设置

1. 桌面点开「答题电视锁」→ **首先要求输入家长进入密码**（默认 `1234`）；
2. 各按钮按遥控器 OK 键循环切换数值：
   - 观看时长（分钟后进入答题）：15 / 30 / 45 / 60 / 90 / 120
   - 答对每题奖励（分钟）：3 / 5 / 10 / 15
   - 每轮答题数量：3 / 5 / 10 / 20
   - 答错追加题数：1 / 2 / 3
3. 「防卸载保护」：点击开启**设备管理员**；想获得最强保护见第六节；
4. 应用启动后即开始后台守护，**关掉页面也不影响计时**。

## 三、家长 WebUI（手机管理）

1. 手机与电视连同一 Wi-Fi；
2. 浏览器打开电视上显示的地址：`http://电视IP:36789`；
3. 登录：默认账号 `admin`，密码 `123456`；
4. 功能一览：
   - **状态**：观看中 / 答题中 / 休息中、剩余分钟、连续观看时长、待答题数；
   - **操作**：立即开始答题、家长 PIN 解锁、重置观看时长；
   - **规则设置**：观看时长、每轮题数、答对奖励、答错追加、**连续观看多久黑屏休息 + 休息时长**、题库开关（语文/数学/英语）；
   - **密码管理**：修改电视上进入 App 的密码、家长 PIN（WebUI 登录后拥有完整权限）；
   - **防卸载**：查看保护状态、解除/恢复卸载拦截、撤销设备管理员（需电视 PIN）；
   - **题库**：四选一添加、删除、**批量导入 txt、导出 txt**；
   - **账号安全**：修改 WebUI 账号密码。

### 题库 txt 格式（便于 AI 生成后批量导入）

每行一题，竖线分隔：

```
题干|选项A|选项B|选项C|选项D|正确字母|科目
```

示例：

```
「暖」的拼音是？|nuǎn|luǎn|nüǎn|nuan|A|语文
23 + 19 = ?|42|43|41|52|A|数学
「school」的中文意思是？|医院|学校|公园|商店|B|英语
```

- `#` 开头的行为注释，可空行；科目可省略（用页面上的默认科目）；
- 给 AI（如 ChatGPT/Claude）的提示词示例：

> 请生成 50 道小学二年级选择题，语文、数学、英语混合，每行格式为
> `题干|选项A|选项B|选项C|选项D|正确字母|科目`，不要输出其他内容。

生成后直接粘贴到 WebUI 的「批量导入」文本框，点导入即可。

## 四、孩子使用流程

1. 电视开机 → 应用自启；若上轮答题未答完，**直接进入答题页**；
2. 答题页用遥控器上下键选答案、OK 提交；
3. 答对 → 奖励分钟数 + 提示后继续；答错 → 追加题目；
4. 本轮全部答完 → 视频自动恢复播放，观看倒计时继续；
5. **连续观看达到设定时长 → 强制黑屏休息**（到点自动恢复可看）；
6. 观看倒计时用完 → 再次进入答题页。

## 五、开机自启与后台常驻

本应用采用三重保活：

1. 开机广播（`BOOT_COMPLETED`、`LOCKED_BOOT_COMPLETED` 等）；
2. 前台服务 + `START_STICKY`，被杀后系统自动重启；
3. AlarmManager 每分钟心跳，服务被杀后自动拉起。

**注意事项（国产电视通用坑）**：

- 小米电视：「安全中心」或「设置 → 应用 → 自启动管理」里允许本应用自启动；把本应用加入后台清理白名单；
- 海信：设置 → 应用管理 → 权限管理 → 自启动管理；
- 若仍被系统级清理杀掉，升级为设备所有者可豁免（见第六节）。

## 六、防卸载（设备管理员 / 设备所有者）

### 方式 1：设备管理员（一键，App 内开启）

设置页点「防卸载保护」→ 按提示授权。开启后：
- 电视「设置 → 应用」中本应用**无法直接卸载**（需先撤销管理员）；
- 想撤销：WebUI「防卸载」卡片输入 PIN → 撤销设备管理员。

### 方式 2：设备所有者（最强，电脑执行一次）

```bash
adb connect <电视IP>:5555
adb shell dpm set-device-owner com.quiztv.lock/.AdminReceiver
```

升级后：
- 卸载按钮被**彻底禁用**（孩子无解）；
- 免受国产 TV 自启动白名单限制，**后台常驻与开机自启更可靠**；
- 恢复方法：WebUI「防卸载 → 解除防卸载」输入 PIN；或
  `adb shell dpm remove-device-owner com.quiztv.lock/.AdminReceiver`。

> 若命令报 `not allowed`：电视上已有其他设备管理员或账号，需先移除；
> 部分品牌电视需恢复出厂后才能设置设备所有者，量力而为。

## 七、注意事项

- 「自动暂停播放」通过媒体键 `KEYCODE_MEDIA_PAUSE` 实现，对系统播放器、大部分国产视频 App 有效；
- 卸载应用即彻底解除所有限制（防卸载开启后需先按第六节解除）；
- 升级安装新版本时，因使用**固定自有签名**，可直接覆盖安装，不必卸载。
